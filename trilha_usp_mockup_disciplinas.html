O que você vai aprender

Modelagem conceitual e lógica de dados, álgebra relacional, normalização, SQL (DDL/DML/consultas) e fundamentos de projeto de bancos de dados relacionais. Base direta para Banco de Dados II e para os módulos de BI usados em estágios.

Conceitos mais cobrados
  • 1 Modelo Entidade-Relacionamento (MER/DER)
  • 2 Normalização (1FN, 2FN, 3FN, BCNF)
  • 3 Álgebra relacional e consultas SQL
  • 4 Integridade referencial e chaves estrangeiras
  • 5 Views, joins e subconsultas
Formato de avaliação
Prova 1 — Modelagem30%

Questões dissertativas de MER e normalização.

Prova 2 — SQL35%

Consultas práticas em SQL, com banco fornecido em laboratório.

Trabalho em grupo35%

Projeto de banco de dados completo, do modelo conceitual à implementação.
