8,2 / 10 · 47 avaliações

Ementa

Modelagem conceitual e lógica de dados, álgebra relacional, normalização, SQL (DDL/DML/consultas) e fundamentos de projeto de bancos de dados relacionais. Base direta para Banco de Dados II e para os módulos de inteligência de negócios utilizados em estágios.

Conceitos mais cobrados
  • Modelo Entidade-Relacionamento (MER/DER)
  • Normalização (1FN, 2FN, 3FN, BCNF)
  • Álgebra relacional e consultas SQL
  • Integridade referencial e chaves estrangeiras
  • Views, joins e subconsultas
Formato de avaliação
Prova 1 — Modelagem30%

Questões dissertativas de MER e normalização.

Prova 2 — SQL35%

Consultas práticas em SQL, com banco fornecido em laboratório.

Trabalho em grupo35%

Projeto de banco de dados completo, do modelo conceitual à implementação.
